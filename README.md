# Numerical Differentiation of Elliptical Planetary Orbits

## Project Overview

This computational physics project models the elliptical orbits of all eight planets in the Solar System. Discrete position data are generated by solving Kepler's equation, and numerical differentiation is used to calculate each planet's orbital velocity and acceleration.

The project compares three first-derivative methods:

- Forward difference
- Backward difference
- Central difference

Acceleration is calculated with the three-point central second derivative. The numerical results are compared with analytical values to investigate truncation error, time-step dependence, and numerical convergence.

## Physical Quantities Calculated

The program calculates:

- Two-dimensional orbital position
- Perihelion and aphelion distances
- Velocity components and orbital speed
- Acceleration components and magnitude
- Mean absolute numerical error
- Error convergence as the time step decreases

## Numerical Methods

For discrete position data \(f(t)\), the first derivative is estimated using forward, backward, and central finite differences:

$$
f'_{\text{forward}}(t_i)
\approx \frac{f_{i+1}-f_i}{\Delta t}
$$

$$
f'_{\text{backward}}(t_i)
\approx \frac{f_i-f_{i-1}}{\Delta t}
$$

$$
f'_{\text{central}}(t_i)
\approx \frac{f_{i+1}-f_{i-1}}{2\Delta t}
$$

The second derivative is estimated with the three-point central-difference formula:

$$
f''(t_i)
\approx \frac{f_{i+1}-2f_i+f_{i-1}}{(\Delta t)^2}
$$

Because an orbit is periodic, the numerical methods connect the final data point back to the first data point.

## Generated Data

### `planetary_summary.csv`

Contains orbital properties, perihelion and aphelion distances, maximum and minimum speeds, maximum and minimum accelerations, and numerical errors for all eight planets.

### `error_convergence.csv`

Contains Mercury's numerical errors for several time-step sizes. Mercury is used for the convergence study because it has the largest orbital eccentricity of the eight planets and therefore provides the most demanding test in this model.

## Main Findings

- Mercury reaches the greatest orbital speed and acceleration and shows the largest variation between perihelion and aphelion.
- The outer planets move more slowly and experience smaller gravitational accelerations.
- The forward- and backward-difference methods show first-order convergence.
- The central-difference velocity and three-point acceleration methods show approximately second-order convergence.
- For the tested time steps, the central-difference method provides the most accurate velocity estimate.

## Model Limitations

This project uses ideal two-dimensional Keplerian orbits with fixed orbital elements. It does not include planetary interactions, orbital inclination, precession, or other perturbations. The model is intended to demonstrate numerical differentiation and convergence rather than produce high-precision ephemerides.
